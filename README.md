# Dispatch Platinum Guide (PS5)

A one-page, phone-friendly walkthrough for the Dispatch platinum:

- **Start:** the roadmap (Run 1, the Shroud replay, the Slot 2 cleanup, Run 2) and how the four save slots are used
- **Trophies:** all 36 with filters, tick boxes and a progress code for moving ticks between devices
- **E1 to E8:** every story choice for both runs, plus who to send on every dispatch call
- **Hacks:** all 28 hacking puzzles with lock codes, routes and video links
- **Heroes, Cleanup, Sources**

Everything is in `index.html`, with no build step. Ticks are stored in each browser's local storage.

## Hosting on GitHub Pages

1. Put `index.html`, `apple-touch-icon.png` and this README at the root of a public repo.
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, and pick **main** and **/ (root)**.
3. After a minute or two the site is live at `https://<username>.github.io/<repo>/`.

On iPhone, open the site in Safari and use **Share → Add to Home Screen** to launch it like an app.

Spoilers for the whole story. The guide is compiled from the community guides listed on the Sources tab.
